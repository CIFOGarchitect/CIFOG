## III. THE PACE PLAN (PERSONAL ADAPTIVE COMMS)
*Failure to plan is planning to fail.* Use this hierarchy to maintain connectivity:

* **P - PRIMARY:** Local/Daily (Cell, Mesh, Internet).
* **A - ALTERNATE:** Vanguard CH 01 (**WARPIGEON**).
* **C - CONTINGENCY:** The **3-3-3 Rule** (Top of hour, CH 3, 3 mins).
* **E - EMERGENCY:** Monitoring **VCALL10 / UTAC1** for rescue instructions.
